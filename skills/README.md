# Skills in this repository

Each folder below is a complete, installable Agent Skill. Copy the **whole folder** — `SKILL.md` plus `references/`, `agents/`, and `LICENSE.txt`. Copying only `SKILL.md` will fail: the procedure loads the reference files on demand.

| Folder | Title | Install this when |
| --- | --- | --- |
| [`monitor-and-regulate-thinking/`](monitor-and-regulate-thinking/) | Simulated Metacognition | You want the agent to separate what is known from what is assumed, and to change strategy when reasoning stalls |
| [`create-through-recomposition/`](create-through-recomposition/) | Simulated Creative Cognition | You want structurally different ideas, not synonym lists — naming, narrative, design, or a stuck representation |
| [`manage-working-context/`](manage-working-context/) | Simulated Working Memory | Work will outlive the context window: long sessions, compaction, thread switching, or reducing a dump |

The two domain skills work without the runtime. Install one, two, or all three.

Step-by-step copy commands for Cursor, Claude Code, Codex, and the generic Agent Skills path: see [`INSTALL.md`](../INSTALL.md).
