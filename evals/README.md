# Prompts

Paste-ready prompts for trying the skills. Each line in `prompts/*.jsonl` is one request plus `must` / `must_not` checks.

| File | Skill |
| --- | --- |
| `prompts/monitor-and-regulate-thinking.jsonl` | Simulated Metacognition |
| `prompts/create-through-recomposition.jsonl` | Simulated Creative Cognition |
| `prompts/manage-working-context.jsonl` | Simulated Working Memory |
| `prompts/cross-skill.jsonl` | Two or more skills together |
| `smoke-test/` | A short hand-run subset |

Install the matching skill first. One prompt per new chat. Do not invoke with `/name` unless you are testing the procedure rather than the trigger.
